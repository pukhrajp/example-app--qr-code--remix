# Cursor Style Generator Documentation

## Overview

The Cursor Style Generator is a utility module that generates CSS code for custom cursors in Shopify storefronts. It provides a secure, validated, and optimized way to apply custom cursor images with support for hotspot positioning, size scaling, and hover states.

---

## Module: `cursorStyleGenerator.js`

**Location:** `app/utils/storefront/cursorStyleGenerator.js`

**Purpose:** Generate CSS for Theme App Extension injection

---

## Main Function

### `generateCursorCSS(cursorData)`

Generates CSS styles for custom cursors that can be injected into a Shopify storefront theme.

#### Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `cursorData` | `Object` | Cursor configuration data |
| `cursorData.isEnabled` | `boolean` | Whether cursor is enabled |
| `cursorData.cursor` | `Object\|null` | Cursor details |
| `cursorData.cursor.id` | `number` | Cursor ID |
| `cursorData.cursor.name` | `string` | Cursor name |
| `cursorData.cursor.imageUrl` | `string` | Default cursor image URL |
| `cursorData.cursor.hoverImageUrl` | `string` | Hover state cursor image URL (optional) |
| `cursorData.cursor.hotspotX` | `number` | X coordinate of cursor hotspot (0-128) |
| `cursorData.cursor.hotspotY` | `number` | Y coordinate of cursor hotspot (0-128) |
| `cursorData.cursor.size` | `number` | Cursor size percentage (25-300, default: 100) |

#### Returns

- `string` - Generated CSS code ready for injection
- `null` - If cursor is disabled, data is invalid, or security check fails

#### Examples

##### Example 1: Basic Cursor
```javascript
import { generateCursorCSS } from './app/utils/storefront/cursorStyleGenerator.js';

const cursorData = {
  isEnabled: true,
  cursor: {
    id: 1,
    name: "Arrow Pointer",
    imageUrl: "https://cdn.shopify.com/cursors/arrow.png",
    hotspotX: 0,
    hotspotY: 0,
    size: 100
  }
};

const css = generateCursorCSS(cursorData);
console.log(css);
```

**Output:**
```css
/* Custom Cursor Styles - Generated by Shopify Cursor App */

/* CSS Variables for cursor configuration */
:root {
  --cursor-size: 100;
  --cursor-size-multiplier: 1;
}

/* Apply custom cursor to all elements */
*, *::before, *::after {
  cursor: url('https://cdn.shopify.com/cursors/arrow.png') 0 0, auto !important;
}

/* Ensure cursor applies to body and html */
html, body {
  cursor: url('https://cdn.shopify.com/cursors/arrow.png') 0 0, auto !important;
}
```

##### Example 2: Cursor with Hover State
```javascript
const cursorData = {
  isEnabled: true,
  cursor: {
    imageUrl: "https://cdn.shopify.com/cursors/pointer.png",
    hoverImageUrl: "https://cdn.shopify.com/cursors/pointer-hover.png",
    hotspotX: 10,
    hotspotY: 5,
    size: 150
  }
};

const css = generateCursorCSS(cursorData);
```

**Output includes hover state CSS:**
```css
/* Hover state cursor for interactive elements */
a:hover,
button:hover,
[role="button"]:hover,
input[type="submit"]:hover,
input[type="button"]:hover,
select:hover,
.button:hover,
.btn:hover,
[data-clickable]:hover {
  cursor: url('https://cdn.shopify.com/cursors/pointer-hover.png') 10 5, auto !important;
}
```

##### Example 3: Disabled Cursor
```javascript
const cursorData = {
  isEnabled: false,
  cursor: {
    imageUrl: "https://cdn.shopify.com/cursors/arrow.png"
  }
};

const css = generateCursorCSS(cursorData);
console.log(css); // null
```

##### Example 4: Invalid URL (Security)
```javascript
const cursorData = {
  isEnabled: true,
  cursor: {
    imageUrl: "javascript:alert('XSS')",
    size: 100
  }
};

const css = generateCursorCSS(cursorData);
console.log(css); // null
// Console warning: "Invalid or unsafe imageUrl provided: javascript:alert('XSS')"
```

## Helper Functions

### `sanitizeURL(url)`

Validates and sanitizes a URL for use in CSS to prevent injection attacks.

#### Parameters
- `url` (string) - URL to validate

#### Returns
- `string` - Sanitized URL
- `null` - If URL is invalid or unsafe

#### Security Checks
- ✅ Only allows `http://`, `https://`, and `data:image/` protocols
- ✅ Blocks `javascript:`, `ftp://`, and other dangerous protocols
- ✅ Checks for CSS-breaking characters (quotes, parentheses)
- ✅ Special handling for data URLs

#### Examples
```javascript
sanitizeURL('https://example.com/cursor.png') 
// Returns: 'https://example.com/cursor.png'

sanitizeURL('javascript:alert(1)') 
// Returns: null

sanitizeURL('https://cdn.shopify.com/cursor.png?v=123') 
// Returns: 'https://cdn.shopify.com/cursor.png?v=123'

sanitizeURL('data:image/png;base64,iVBORw0...') 
// Returns: 'data:image/png;base64,iVBORw0...'
```

---

### `validateHotspot(value, defaultValue, min, max)`

Validates and clamps hotspot coordinates to safe bounds.

#### Parameters
- `value` (number) - Coordinate value to validate
- `defaultValue` (number) - Default value if invalid (default: 0)
- `min` (number) - Minimum allowed value (default: 0)
- `max` (number) - Maximum allowed value (default: 128)

#### Returns
- `number` - Validated and clamped coordinate (integer)

#### Examples
```javascript
validateHotspot(10, 0, 0, 128)  // Returns: 10
validateHotspot(500, 0, 0, 128) // Returns: 128 (clamped to max)
validateHotspot(-10, 0, 0, 128) // Returns: 0 (clamped to min)
validateHotspot(NaN, 0, 0, 128) // Returns: 0 (default)
validateHotspot('not a number', 0, 0, 128) // Returns: 0 (default)
```

---

### `validateSize(size)`

Validates cursor size parameter and clamps to reasonable bounds.

#### Parameters
- `size` (number) - Size percentage

#### Returns
- `number` - Validated size between 25 and 300 (integer)

#### Examples
```javascript
validateSize(100)  // Returns: 100
validateSize(150)  // Returns: 150
validateSize(500)  // Returns: 300 (clamped to max)
validateSize(10)   // Returns: 25 (clamped to min)
validateSize(0)    // Returns: 100 (default)
validateSize(-50)  // Returns: 100 (default)
validateSize(NaN)  // Returns: 100 (default)
```

## Usage in Theme App Extension

### Step 1: Fetch Cursor Data from API

```javascript
const response = await fetch('/api/cursor-data?shop=my-store.myshopify.com');
const data = await response.json();
```

### Step 2: Generate CSS

```javascript
import { generateCursorCSS } from './cursorStyleGenerator.js';

const css = generateCursorCSS(data);
```

### Step 3: Inject CSS into Theme

```javascript
if (css) {
  const styleElement = document.createElement('style');
  styleElement.id = 'shopify-custom-cursor-styles';
  styleElement.textContent = css;
  document.head.appendChild(styleElement);
}
```

## Security Features

### 1. URL Validation
- Only `https://`, `http://`, and `data:image/` URLs are allowed
- Blocks dangerous protocols (`javascript:`, `ftp:`, etc.)
- Prevents CSS injection via quotes and parentheses

### 2. Input Sanitization
- All numeric values are validated and clamped
- Non-numeric values fallback to safe defaults
- NaN and Infinity are handled gracefully

### 3. Bounds Checking
- Hotspot coordinates: 0-128 pixels
- Cursor size: 25%-300%
- All values are floored to integers

### 4. Error Handling
- Returns `null` for invalid data (fail safely)
- Console warnings for security issues
- No exceptions thrown (defensive programming)

## CSS Custom Properties

The generator provides CSS variables for JavaScript integration:

```css
:root {
  --cursor-size: 150;           /* Size percentage */
  --cursor-size-multiplier: 1.5; /* Size as decimal multiplier */
}
```

**Usage in JavaScript:**
```javascript
const size = getComputedStyle(document.documentElement)
  .getPropertyValue('--cursor-size');
console.log('Cursor size:', size); // "150"
```

## Error Scenarios

| Scenario | Behavior |
|----------|----------|
| `isEnabled: false` | Returns `null` |
| Missing `imageUrl` | Returns `null` |
| Invalid URL protocol | Returns `null`, logs warning |
| CSS injection attempt | Returns `null`, logs warning |
| Invalid hotspot values | Uses default (0, 0) |
| Invalid size values | Uses default (100) |
| Missing `hoverImageUrl` | No hover CSS generated |
