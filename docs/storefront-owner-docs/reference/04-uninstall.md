### Uninstall / disable

### Disable the cursor without uninstalling

1. Shopify Admin -> Online Store -> Themes -> Customize
2. Theme settings -> App embeds
3. Find **Custom Cursor**
4. Toggle it **Off**
5. Click **Save**

This stops the cursor from appearing immediately.

### Uninstall the app

1. Shopify Admin -> Apps
2. Find **Custom Cursor**
3. Uninstall

Recommended after uninstall:

- Confirm the app embed is disabled
- Hard refresh your storefront

### What happens to uploaded cursors?

Uploaded cursors are stored by the app. If you uninstall, they are no longer applied to the storefront.

If you reinstall later, you may need to set up the embed again and publish a cursor.
