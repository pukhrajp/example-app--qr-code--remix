### FAQ

### Does Shopify require me to enable translation/localization for the app embed?

No. App embeds work by default.

(For this app, the embed settings currently display in English.)

### Can I enable the cursor only on certain pages?

Right now, the cursor is applied storefront-wide when the app embed is enabled.

### Does this work on mobile?

You can enable it, but it's recommended to keep **Disable on Mobile Devices** ON.

Mobile and tablet users don't usually use a mouse cursor, and custom cursors can feel confusing on touch devices.

### How fast do changes go live?

After you click **Save & Publish**, changes will apply on the storefront.

For performance, browsers may cache settings for up to **5 minutes**.

### What file types can I upload?

- `.png`, `.svg`, `.ico`, `.cur`

### Do I need a hover cursor?

No. It's optional.

If you provide one, it will show when customers hover buttons/links and other interactive elements.

### Can I remove a custom cursor I uploaded?

Yes. You can delete custom cursors from the gallery.

Tip: If it's currently published, publish a different cursor first.
