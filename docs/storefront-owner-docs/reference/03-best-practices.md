### Best practices

### Keep it subtle

Cursors are a small UI detail. If they are too large or flashy, they can distract customers.

### Choose a good hotspot

- Arrow tip -> hotspot at the tip
- Round cursor -> hotspot near the center

A wrong hotspot makes the store feel "hard to click".

### Use hover cursor thoughtfully

Hover cursors are great for:

- call-to-action buttons
- links
- important interactive elements

Make sure hover cursor is still readable and not too big.

### Test common customer flows

Before going live, test:

- Home page
- Collection page
- Product page
- Cart page
- Checkout entry (as far as your theme allows)

### Keep mobile disabled (recommended)

Keep **Disable on Mobile Devices** ON unless you have a strong reason.

### After big theme updates

If you change your theme or install other apps that inject CSS/JS:

- Re-check that the **Custom Cursor** app embed is still enabled
- Verify cursor is still correct on the storefront
