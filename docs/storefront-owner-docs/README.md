### Custom Cursor - Storefront Owner Documentation

Welcome! This documentation explains how to set up and use the **Custom Cursor** app on your Shopify storefront.

### Who this is for

- Store owners and staff who manage the storefront experience
- Anyone who can access **Shopify Admin** and **Theme Editor**

### What this app does (in simple terms)

- Lets you pick a custom mouse cursor for your storefront
- Supports a **default cursor** and an optional **hover cursor** (when hovering buttons/links)
- Lets you upload your own custom cursor images
- Lets you adjust cursor size and hotspot (click point)

### How it works (high level)

- You configure the cursor inside the app (in Shopify Admin)
- You enable the **Custom Cursor** **App embed** in your theme
- The cursor is applied storefront-wide by the theme app extension
