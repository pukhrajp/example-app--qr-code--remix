### Hotspot and cursor size

This guide explains two important settings:

- **Hotspot** (where the click point is)
- **Cursor size** (how big the cursor appears)

### What is a hotspot?

The hotspot is the exact pixel in the cursor image that acts as the "click point".

Examples:

- For an arrow cursor, the hotspot is usually the arrow tip.
- For a round cursor, the hotspot is often the center.

If the hotspot is wrong, customers may feel like clicks happen "off" from where they point.

### Setting the hotspot (custom uploads)

When uploading a custom cursor, you can select a hotspot visually.

Recommended:

- Set the hotspot to the pixel you want to act as the click point.
- Use **Reset to center** if you want a quick default.

### Cursor size (16-64px)

You can change cursor size in the app:

1. Open the cursor you want.
2. Use the **Cursor size** slider.
3. Click **Save & Publish**.

Tip: Keep size reasonable. Very large cursors can distract customers.

### Storefront update timing

For performance, storefront browsers cache cursor settings for about **5 minutes**.

If you change hotspot/size and don't see it right away:

- Wait a few minutes, or
- See `reference/01-troubleshooting.md`.
