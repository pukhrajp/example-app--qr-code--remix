### Upload custom cursors

You can upload your own cursor images and use them like the built-in gallery cursors.

### What you can upload

- **Default cursor image** (required)
- **Hover cursor image** (optional)
  - Shown when customers hover interactive elements like buttons and links

### Supported file types

- PNG (`.png`)
- SVG (`.svg`)
- ICO (`.ico`)
- CUR (`.cur`)

### File size limit

- Max size: **1 MB** per file

### Upload steps

1. Open **Shopify Admin -> Apps -> Custom Cursor**.
2. In the left panel, open the **Upload** tab.
3. Upload the **Default Cursor** image.
4. (Optional) Upload the **Hover Cursor** image.
5. Enter:
   - **Name** (required)
   - **Description** (optional)
6. (Optional) Set hotspot using the hotspot picker (recommended).
7. Click **Upload**.

After upload:

- Your cursor appears in the gallery under the **CUSTOM** category.
- Select it and click **Save & Publish** to make it live.

### Deleting a custom cursor

Custom cursors can be removed from the gallery.

- If you delete a cursor that is currently published, the app may fall back to "no active cursor" until you publish another cursor.

Tip: publish a different cursor before deleting the currently active one.
