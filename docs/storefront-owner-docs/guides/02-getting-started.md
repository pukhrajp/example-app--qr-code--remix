### Getting started

This guide gets you from "installed" -> "working on the storefront".

### Step 1: Install the app

1. In Shopify Admin, install **Custom Cursor**.
2. Approve requested permissions.

### Step 2: Open the app dashboard

1. Go to **Shopify Admin**.
2. Open **Apps**.
3. Select **Custom Cursor**.

### Step 3: Enable the theme app embed (required)

Your cursor won't show on the storefront until the app embed is enabled.

Follow: `guides/03-enable-app-embed.md`

### Step 4: Choose a cursor and publish

Follow: `guides/04-choose-and-publish-cursor.md`

### Step 5: Verify on the storefront

1. Open your storefront in a new tab.
2. Hard refresh:
   - Windows: **Ctrl + Shift + R**
   - Mac: **Cmd + Shift + R**
3. Move your mouse around:
   - Normal areas should show the custom cursor
   - Hovering buttons/links should show the hover cursor (if set)

If something isn't working, go to: `reference/01-troubleshooting.md`
