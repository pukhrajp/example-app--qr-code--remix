### Introduction

The **Custom Cursor** app helps you change your storefront's mouse cursor to match your brand.

### Key features

- **Cursor gallery**: choose from built-in cursors
- **Preview before publishing**: preview changes in the app without affecting your live store until you click **Save & Publish**
- **Hover cursor**: show a different cursor when customers hover buttons/links (optional)
- **Custom cursor upload**: upload your own cursor images
- **Hotspot picker**: choose the exact click point
- **Cursor sizing**: adjust cursor size (16-64px)
- **Mobile controls**: option to disable cursor on mobile/tablet (recommended)

### What you need

- Access to **Shopify Admin**
- Permission to edit your theme (**Online Store -> Themes -> Customize**)

### Important notes

- The cursor is applied using a **Theme App Extension** (App embed). You don't need to edit theme code.
- The storefront caches cursor settings in the browser for about **5 minutes** for speed. If you change settings and don't see it immediately, see `reference/01-troubleshooting.md`.
