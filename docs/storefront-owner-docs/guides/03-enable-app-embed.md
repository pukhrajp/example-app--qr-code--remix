### Enable the Custom Cursor app embed (Theme Editor)

The app uses an **App embed** to apply the cursor storefront-wide.

### Steps

1. Go to **Shopify Admin -> Online Store -> Themes**.
2. Find your **live** theme.
3. Click **Customize**.
4. In the Theme Editor, open **Theme settings**.
5. Click **App embeds**.
6. Find **Custom Cursor**.
7. Toggle it **On**.
8. Click **Save** (top right).

### App embed settings

Inside the embed, you'll see:

- **Enable Custom Cursor**
  - Keep this **On** to apply the cursor.
- **Disable on Mobile Devices**
  - Recommended **On** (touch devices don't typically need custom cursors).

### Notes

- If the cursor doesn't appear, confirm the embed is enabled and you clicked **Save**.
- If you test using Chrome DevTools responsive mode, the app may detect a tablet/mobile and disable the cursor when **Disable on Mobile Devices** is enabled.
