### Setup checklist (storefront owners)

Use this as a quick "did I do everything?" list.

- [ ] App installed in Shopify Admin
- [ ] Opened the app dashboard
- [ ] Selected a cursor in the gallery
- [ ] Clicked **Save & Publish**
- [ ] Enabled **Custom Cursor** in **Online Store -> Themes -> Customize -> Theme settings -> App embeds**
- [ ] Clicked **Save** in the theme editor
- [ ] Verified on storefront (hard refresh)
- [ ] (Optional) Uploaded a custom cursor and published it
- [ ] (Optional) Adjusted hotspot and cursor size and published
- [ ] (Optional) Kept "Disable on Mobile Devices" enabled
